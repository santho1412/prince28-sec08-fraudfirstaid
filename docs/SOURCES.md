
# FraudFirstAid - Source Register

Reviewed: 23 November 2026

This register identifies authoritative sources for fraud-response guidance.
Only public information is used. Do not store real victim names, account
numbers, card numbers, OTPs, or other personal financial information.

## Data handling

The project may store public document metadata and guidance fields:

`id, issuer, doc_type, number, date, topic, scam_type, deadline_days`

Do not collect or store real victim identities, bank account numbers, card
numbers, passwords, PINs, OTPs, or other sensitive personal information.

## Review notes

- Confirm the latest RBI customer-liability directions before presenting deadlines or liability rules as current.
- Check the current RBI Integrated Ombudsman Scheme before advising users.
- Retain the 2021 scheme for historical cases where it remains applicable.
- The exact bank-policy sources are still to be selected and recorded.
- Recheck source links and terms before each substantial content update.
