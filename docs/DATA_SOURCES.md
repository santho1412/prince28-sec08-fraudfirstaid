## Data handling rules

- Only use publicly available official information.
- Do not store victim names, phone numbers, bank account numbers or card numbers.
- Use null for unavailable information.
- Verify document dates and reference numbers against original sources.
- Review superseded directions before using them as current guidance.
- Clearly identify historical or withdrawn directions.
